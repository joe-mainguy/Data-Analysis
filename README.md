# Module 12: GreenGrocer Business Analytics
This repository contains a comprehensive data analysis project focused on "GreenGrocer," a multi-location retail chain in Florida. The project utilizes Python to process simulated sales, customer, and operational data to derive actionable business insights.

## Files Included
- `moudle12-assignment.py`: The main Python script containing data generation, analysis functions, and visualization logic.

## What I Practiced
In this assignment, I applied advanced Python programming and data science principles to a business context:
- **Descriptive Analytics**: Summarized current performance by calculating total sales, profit margins, and departmental performance across five Florida store locations.
- **Diagnostic Analytics**: Explored relationships between variables, such as the correlation between store square footage and annual revenue[cite: 1].
- **Predictive Analytics**: Developed basic forecasting models using linear regression to predict future sales based on store size[cite: 1].
- **Data Visualization**: Created bar charts, pie charts, and time-series plots using `matplotlib` to visualize seasonal trends and efficiency metrics[cite: 1].
- **Library Integration**: Leveraged `pandas` for data manipulation, `numpy` for statistical generation, and `scipy` for advanced data modeling[cite: 1].

## Key Insights 
- Identified high-margin opportunities within the "Prepared Foods" department
- Analyzed customer loyalty tiers and spending habits across different demographic segments
- Developed recommendations for labor reallocation and future store expansion based on performance data
